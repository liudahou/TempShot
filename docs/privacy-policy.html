TempShot / 一刻相册 Privacy Policy Effective date: October 12, 2026 Developer: Liu Yijia Contact: liudahou666@gmail.com 1. About TempShot TempShot, also known as 一刻相册, is an Android application with the package name com.tempshot. It helps users assign retention periods to newly added images and move expired images to the device's system trash. 2. Data accessed by the app With the user's permission, TempShot accesses images stored on the device and related media information, including file names, storage locations, creation times, favorite status, and trash status. This access is used only to: - Detect newly added images. - Classify camera images, screenshots, and images saved by other apps. - Display images and their expiration status. - Move expired images to or restore images from the system trash. - Perform scheduled background checks. 3. Data collection and sharing TempShot does not upload photos or personal data to the developer or any external server. TempShot does not contain advertising, analytics, tracking, or third-party data collection SDKs. It does not sell or share user data with third parties. All photo processing is performed locally on the user's device. 4. Local storage and retention TempShot stores app preferences, retention rules, image identifiers, expiration times, and image-management status locally on the device. This locally stored app data remains until the user clears the app's data or uninstalls the app. TempShot does not create cloud copies of users' photos. Images moved to the system trash are retained or permanently deleted according to the device operating system and gallery application's trash policy. 5. Permissions Depending on the Android version and features selected by the user, TempShot may request: - Photo and media access, to detect and manage eligible images. - Media management access, to reduce repeated system confirmation prompts when moving images to the trash. - Notification permission, to notify users about expired images. - Permission to receive device restart events, to restore scheduled background checks. Users may revoke these permissions at any time through Android system settings. Some application features may then stop working. 6. User control and deletion Users can stop automatically including new images, change to manual management, revoke permissions, clear TempShot's app data, or uninstall the app. Users can manage, restore, or permanently delete trashed images using the device's system gallery or trash interface. Because TempShot does not transmit user data to the developer, the developer does not hold server-side user data that requires a deletion request. 7. Children's privacy TempShot is a general photo-management utility and is not specifically directed toward children. The app does not knowingly collect personal information from children. 8. Changes to this policy This privacy policy may be updated when the application's functionality or data practices change. The effective date at the top of this page will be updated accordingly. 9.
